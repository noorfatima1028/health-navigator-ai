# Health Navigator AI

Health Navigator AI is a production-ready AI-powered personal health assistant built with FastAPI, PostgreSQL, LangGraph, and Retrieval-Augmented Generation (RAG).

## 🚀 Features

- User Authentication
- Health Profile Management
- Health Records Tracking
- AI Health Assistant
- Medical Report Analysis
- RAG-based Knowledge Base

## 🛠 Tech Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- LangGraph
- Docker
- AWS (Deployment)
